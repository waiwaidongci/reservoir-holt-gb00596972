# 001 初始表结构

应用首次启动以 SQLAlchemy 模型创建表与唯一约束。现有数据表只补建缺失表，升级到修改过字段的版本需要显式迁移。

- `users` 账号角色和加盐密码摘要。
- `level_defs` 液位档位定义，`rank` 唯一且按液位从低到高。
- `baselines` 空池基准，每个档位最多一条库容锚点。
- `experiments` 排水试验，记录排水前后档位、排水量范围与启用状态；停用保留历史。
- `calibration_runs` 校准计算，固化输入快照与解算结果（含确认/待补测/无解诊断）。
- `calibration_tables` 库容表版本，同一时刻只有一个 `active` 版本，发布在单事务内整体切换。
- `table_levels` 发布版本中每个档位的库容与采用的试验证据。
- `audit_events` 记录登录、录入、更正、停用、解算与版本发布动作。
